# 主舞台与月食改版

## 交付范围
保留现有技术栈。主舞台放大、删除天体常驻文字；支持拖动旋转/滚轮缩放/双击复位；右上圆形真实月面预览；03与05默认独立折叠浮层、开合状态本地保存、可恢复默认布局；原滑块、播放、练习保留。

新增2025-09-07月全食事件回放：真实UT1接触时间、不等距七节点、×600播放、拖动和节点跳转；三维本影/半影锥、影面穿行图、铜红月面预览与远交点无食对照。颜色是提亮教学映射，不是实拍曝光或完整辐射传输。模型详见ECLIPSE_MODEL.md。

## 有意未照搬的提示词内容
不改为单文件HTML、不增加农历推算/纬度星历；不把日月距角混作相位角；不把2.6/4.6当所有事件通用比值；未实现自由拖动面板、透明度保存和任意半影/偏食事件生成。上述不是本轮布局与真实全食回放的必要前提。

## 资料
月面纹理：NASA's Scientific Visualization Studio / LRO / LROC，https://svs.gsfc.nasa.gov/4720/ ，原图保存在public/textures/moon.jpg。用户参考照片仅作视觉参考。
事件预报：Eclipse Predictions by Fred Espenak, www.EclipseWise.com，来源与精度记录在科学文档。

## 检查与限制
科学核心扩充至26项测试；浏览器覆盖旧功能、浮层开合/持久化/不改变舞台边界、七节点时间/无食对照/退出恢复、窄屏和播放。旧版本报告属于历史验收，当前结果以本轮执行为准。
三维依赖仍较大，采用懒加载；未验证实际教室投影与所有浏览器。近地月面纹理固定、忽略天平动；月食穿行轨迹是接触约束插值，不供真实天象定位。


最终验证：26项Vitest测试、11项Playwright测试通过；TypeScript与生产构建通过。已检查普通满月、全食、390像素窄屏截图。三维共享包约932KB，懒加载，仍有构建体积提示。
