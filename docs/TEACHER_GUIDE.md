# 教师操作指南

## 开课前
运行 npm run dev，打开终端显示的本地地址。推荐 1600×900 或更高，浏览器缩放100%。模型采用赤道、共面圆轨道与零赤纬，不能用来预报本地真实升落。

## 15分钟探究流程
1. 约3分钟：选新月、上弦、满月、下弦，对照空间与月面。让学生指出太阳照亮月球的一半；地球阴影不是月相成因。
2. 约3分钟：在主导航下拖动农历日期，再播放朔望月。对照月球位置和右上角月面，辨认上半月与下半月的亮边。
3. 约4分钟：展开“一月月相图”，从北极上空沿内圈逆时针追踪月球，对照外圈的地球所见月面。点击某一月相，可同步切换到对应示例日。
4. 约3分钟：选择满月，展开“月出、中天与月落”，解释为何太阳和满月先后相隔约十二小时经过子午线。比较上弦的 12/18/次日 00 时与下弦的 00/06/12 时。
5. 约2分钟：让学生解释“在地平线上方”为什么不保证肉眼可见。太阳背景、天气和实际纬度不在本模型的可见性计算中。

## 太阳视运动（可选约5分钟）

顶部选择“太阳视运动”，打开“观测设置”选择城市和日期。拖动当地时间滑块观察日影，比较北京两个至日的昼长。切换至特罗姆瑟观察极昼和极夜。选择场景圆点或底部知识点，将示意图、数据与实物对照。

地景中的编号 ①–⑤ 是五个知识站点：① 最小楼间距、② 热水器倾角、③ 影长、④ 室内采光、⑤ 遮阳板。点击场景编号或右侧按钮，视角会拉近并在右侧显示公式和实时数据。建议用“冬至正午 / 夏至正午”按钮对比同一站点的两种极端：楼间距按冬至预留；集热板冬至最陡、夏至最平；冬至正午影子最长而夏至最短；室内进深冬至最大、夏至最小；同一块遮阳板夏至几乎遮住整窗、冬至只挡上部。楼间距、影长与采光数据随纬度改变，可让学生回到纬度输入框验证“纬度越高，冬至太阳越低”。

## 操作提示
拖动农历滑块或点选月相会暂停播放。重置回到初一。按“隐藏月相”可遮住右上角的实时月面，供学生推理后再显示验证。农历日为从朔开始计数的模拟日序。模型的大小和距离经过缩放。

## 故障排查
三维不可用时检查浏览器 WebGL/硬件加速；月面与八相图可继续使用。首次加载三维模块可能较慢。投影时可使用浏览器全屏，低分辨率屏幕允许滚动，不隐藏控件。
