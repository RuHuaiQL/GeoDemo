# 月食模型与视觉改版

保留 Vite/React/TypeScript/R3F/Zustand/Vitest/Playwright。月相理想核心不改变。新增独立月食事件时间轴，不把普通满月自动判成月食，不把地方太阳时混作 UT1。

## 数据与精度
回放2025-09-07月全食，采用 Fred Espenak / EclipseWise 的 JPL DE430 预报接触时刻（UT1），不是现场实测。P1 15:28:06.0，U1 16:26:51.0，U2 17:30:36.6，食甚18:11:46.1，U3 18:53:18.0，U4 19:56:53.3，P4 20:55:27.9。全过程5h27m21.9s，全食1h22m41.4s，时间轴不等分。

圆形影面采用该事件平均角半径：月球16′09.8″，本影0.7400°，半影1.2691°，所以直径比约2.747与4.711。平均距离几何近似 R_u(x)=R_e-x(R_s-R_e)/D_s，R_p(x)=R_e+x(R_s+R_e)/D_s；本影收敛、半影发散。影锥图纵向距离压缩，横截面在月距处严格采用事件比值；图中注明两轴不同比例，不能据此量锥角。

月球中心轨迹：按接触时刻约束圆影面切触位置，最近距离0.2721°，分段插值穿行坐标；不是重新求解完整星历。地球观测图北向上、东在左，月球自右向左移动，入本影先蚀左侧东缘。用于接触形态教学，不作秒级影缘定位。食分=(本影半径+月球半径-中心距)/(2月球半径)，可超过1，不等于面积遮挡率。

黄白交角取5.145°，独立交点示意显示近交点望月与远交点望月；远交点横向偏移取 Dmoon sin(5.145°)，超过半影半径与月球半径之和，不发生月食。该对照为几何实验，不是另一真实事件预报。普通月相视图继续使用原零倾角教学模型。

## 纹理、锁定与亮度
NASA SVS CGI Moon Kit / LRO 全球经纬纹理，0°经线居中。预览通过正射球面采样固定近地面，不随相位转动；空间月球近地0°经线始终指地球，随恒星经度同步自转。忽略天平动。光照由表面法向点积决定，绝不把照片里的旧阴影当新的晨昏线。

全食红色来自大气折射与短波瑞利散射，近本影边界相对偏亮；颜色取教学映射而非大气辐射传输求解。约10星等只是量级示例（通量10^-4），不同月食不固定相同。屏幕自动提亮用于看清纹理，不宣称屏幕表现了真实10000倍动态范围。月轮始终完整，半影渐暗、本影铜红，未覆盖区保留受光纹理。
