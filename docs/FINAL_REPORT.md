# 教学版 v1.0 最终验收

日期：2026-11-10。完成约定的本地纯前端实现，未发布到互联网。

## 功能
三维日地月模型、SVG月相与地平天空；八月相名称、四主相快捷按钮；朔望月与地方太阳时滑块；独立播放与倍速；教师隐藏答案、重置；四主相的时刻判断与观测时段练习；页面帮助、教师指南。

## 验证结果
- Vitest：4个文件，22项全部通过。
- Playwright Chromium：8项全部通过，覆盖切换、隐藏、重置、播放暂停、题目验证、跨午夜、键盘方向键和多尺寸无横向溢出。
- TypeScript类型检查和Vite生产构建通过。
- 尺寸：1600×900课堂布局、1366×768、1920×1080、390×844；检查桌面及窄屏截图，修复窄屏太阳标记裁切。
- 核心科学公式未因视觉要求改变；投影面积和照明比例、升落区间与高度、恒星月与朔望月区别均有测试。

## 性能处理
三维模块懒加载、按需渲染、像素比上限1.5；暂停时关闭播放计时器；自转不重绘不变的月面。相机按画布宽高比适配。未进行真实低端设备帧率或内存基准测试。

## 交付与限制
运行方式见根目录README.md，产物为dist。主脚本约236KB（gzip75KB），三维模块约934KB（gzip251KB）；Vite仍提示大模块，这是已记录的加载体积限制，未通过调高警告阈值隐藏。

模型固定赤道、共面圆轨道、零赤纬，忽略折射和视差，不用于真实地区预报。地平线上方不等于肉眼可见。未保存成绩、未建数据库。低分辨率和练习反馈展开时允许纵向滚动。

实际教室投影、真实低端设备、Firefox/Safari与屏幕阅读器完整审计未执行；键盘基本操作已验证。现场可按TEACHER_GUIDE.md进行15分钟试讲，检查后排可读性、WebGL性能和设备缩放设置。这些现场项不伪记为通过。

## 追加：太阳视运动模块（2026-11-10）

在月相与月食之外新增独立太阳周日视运动模块：日期、城市/经纬度、北京时间滑块、地平线以上轨迹、上中天点击高度角、日出日落与极昼极夜，以及含草地建筑与实时阴影的三维昼夜场景。地景新增五个可点击知识站点（楼间距、热水器倾角、影长、室内采光、遮阳板），点击后相机拉近并显示实时数据。科学公式、局限与验收见 SOLAR_MODEL.md 和 ACCEPTANCE.md 阶段五；本轮 Vitest 40项、Playwright 16项通过，TypeScript 与生产构建通过。
