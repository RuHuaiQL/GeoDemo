# GeoDemo

面向教师课堂演示与学生自主探究，纯前端、简体中文，优先适配 16:9 投影与电脑。

阶段一：Vite + React + TypeScript 初始化，科学核心、典型月相测试、最小页面。提供周期与地方太阳时输入、主要月相选择、答案隐藏与重置。不得开始三维渲染。

后续经确认：Three.js / React Three Fiber 空间模型、SVG 月面、天空观测三视图共享核心输出；加入预测观测任务。Tailwind CSS 管理样式，Zustand 管理状态，Vitest 和 Playwright 验证。

目录：src/science 为无 UI 依赖计算；src/store 为交互状态；src/App.tsx 为第一阶段页面；tests 为端到端测试；docs 为模型及验收依据。

不包含真实星历、数据库、账户、自动定位或实际月食预测。阶段一不发布网站。


阶段三：独立朔望月/自转播放、0.5/1/2倍速、四主相预测练习；题目固定条件，验证时同步三视图；不引入账户、分数持久化或真实可见性预报。

阶段四：观测时段选择题覆盖四主相，跨午夜明确标注次日，不包含出落瞬间。区间判断与核心地平高度采样一致；切换题型清空反馈。空间模型添加随天体移动的名称并放大视野。教师流程见 TEACHER_GUIDE.md。
