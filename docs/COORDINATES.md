# 坐标与视图契约

核心统一使用右手系：地心原点，+Z 为北极，XY 为共同轨道面；初始太阳位于 +X，从 +Z 向原点看逆时针为东向公转。长度使用单位地月距离，仅示意不按比例。角度弧度，显示时转为度。

惯性单位向量：太阳 (cos λs,sin λs,0)，月球 (cos λm,sin λm,0)。太阳方向随年运动，月球方向按恒星月运动；不能将 D 直接当恒星经度。太阳固定的共转视图可以使用 (cos D,sin D,0)，必须标明参考系。

未来 Three.js 适配：核心 (x,y,z) 映射至场景 (x,z,-y)，保持右手性，场景 +Y 朝北；不在渲染器重新计算天文参数。

未来月面 SVG：天球北向上、东在屏幕左侧，盈月右亮、亏月左亮，非本地地平旋转姿态。单位月盘屏幕 x 向右、y 向上，z 向观测者；光方向 (sin D,0,-cos D)，表面法向 (x,y,sqrt(1-x²-y²)) 与光方向点积>0 为亮面，终止线由点积=0 定义。面积积分须与 k 一致。

天空输出采用 ENU（东、北、天顶），方位自北向东计量；天顶/天底 null 必须显示“未定义”。地方太阳时只转动观测参考系，不更改 p 或恒星位置。


月食地球观测图沿用北上东左；月心从屏幕右向左穿行。月面纹理经纬映射及接触插值精度见 ECLIPSE_MODEL.md。空间纹理0°经线随恒星经度同步自转并恒指地心。

太阳视运动场景使用同一套 ENU（东、北、天顶）单位向量，映射为场景 (东, 天顶, −北)，保持右手性；太阳高度角、方位角与日出日落全部在 science 层计算，地景尺度不参与天文计算。视运动公式与局限见 SOLAR_MODEL.md。
