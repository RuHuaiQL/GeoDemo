# 阶段一验收

- 四主相及八中心名称正确；照明为 0、1/2、1、1/2。
- 四主相的出/中/落时刻符合模型表；上中天高度90°，出落高度0°。
- 负时间、跨周期、24小时归一化，拒绝 NaN/Infinity。
- 一个恒星月后惯性月球回原位而月相尚未重复；一个朔望月后月相重复但惯性位置不同。
- 改地方太阳时不改月相；跨大量采样 k 在[0,1]，ENU 长度为1；浮点误差容许 1e-8。
- Vitest 核心测试、TypeScript 类型检查和 Vite 生产构建必须成功。
- Playwright 验证主要月相、隐藏答案、重置和滑块操作；浏览器不可用须明确报告未验证。
- 页面显示教学理想模型、赤道假设与非实际预报；无三维渲染、无数据库。

后续验收：月面亮区面积与 k、三个视图共享状态、课堂投影可读性、键盘操作。需用户确认后实施。

## 阶段二

三个视图消费单一 calculate 结果；投影亮区面积在 32 个周期采样点上与 k 误差小于 0.0001；盈亏方向正确；地方太阳时不改变惯性位置或月面。浏览器验证 Canvas 加载、视角切换、满月/午夜天顶联动、隐藏月面与天空答案，无未捕获异常。三维失败须给出降级提示。


阶段三验收：播放互斥、周期回绕、手动输入暂停、重置停播；预测未选择不可验证，验证同步三视图，下一题清空反馈；1600×900下重置控件完整可见。

阶段四：观测时段选择题覆盖四主相，跨午夜明确标注次日，不包含出落瞬间。区间判断与核心地平高度采样一致；切换题型清空反馈。空间模型添加随天体移动的名称并放大视野。教师流程见 TEACHER_GUIDE.md。

## 阶段五（太阳视运动）

- 日期、典型城市与手动经纬度可切换；北京时间滑块扫描一天；经度改变北京时间的日出日落。
- 轨迹只显示地平线以上部分；极昼显示闭合轨迹，极夜不显示日面和轨迹，日出日落栏给出明确提示。
- 点击三维轨迹上的“上中天”标记可显示太阳高度角；控制面板按钮提供等效键盘入口。
- 日出、上中天、日落、昼长与正午高度读数一致；几何日出日落忽略大气折射，页面和 SOLAR_MODEL.md 明确说明。
- 三维场景含草地、建筑、树木、实时阴影、昼夜天色与夜间窗灯；窄屏无横向溢出。
- 地景五个知识站点（楼间距、热水器倾角、影长、室内采光、遮阳板）各有精细模型；点击三维编号或面板按钮后相机拉近，数据面板实时显示公式和数值。
- 三维编号点击、面板切换、冬至/夏至正午预设与返回全景均有端到端覆盖；太阳轨迹半径大于地景最大外廓，避免太阳与建筑穿模。
- 验证：Vitest 40项、Playwright 16项通过；TypeScript 类型检查与生产构建通过；检查北京夏至、冬季站点、夜间和 390 像素窄屏截图。
